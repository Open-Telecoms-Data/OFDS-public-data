The Bofinet OFDS map is a hand-coded approximation of the network map at https://www.bofinet.co.bw/networks ([archive.org](https://web.archive.org/web/20250515073229/https://www.bofinet.co.bw/networks)).  Some effort has been made to ensure that the Points of Presence are accurate but the network paths between the PoPs are approximations only.  It is intended for demonstration purposes only.
