# Réseau national haut débit #

This map was digitized from the publicly available network map of the Backbone National de Guinée on the [ANSUT website](https://ansut.ci/infrastructures/reseau-national-haut-debit/) ([archive copy](https://web.archive.org/web/20240619154841/https://ansut.ci/infrastructures/reseau-national-haut-debit/)). It is not a perfect transcription as some routes and locations are hard to make out and/or geo-locate.  Routes are approximations based on the assumption that the fibre follows road infrastructure.
