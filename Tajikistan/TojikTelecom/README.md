The TojikTelecom OFDS map is a hand-coded, rough approximation of the network map on page 19 of the 2017 ISOC report entitled  [Tajikistan Internet Exchange Point Environment Assessment](https://www.internetsociety.org/wp-content/uploads/2017/08/ISOC-Tajikistan-IXP-assessment.pdf). It is intended for demonstration purposes only.
