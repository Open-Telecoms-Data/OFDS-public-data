# GCN

The GCN OFDS map is a hand-coded, rough approximation of the network map available on their [website](https://gcn.bg/images/map/BGMap_en.pdf). Archived version of the network map [here](https://web.archive.org/web/20260510093044/http://www.gcn.bg/GCN_bg_backbone_en.html). It is intended for demonstration purposes only.
