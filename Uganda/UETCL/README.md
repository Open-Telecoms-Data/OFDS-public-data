The UETCL OFDS map is a hand-coded, very rough approximation of the network map at https://uetcl.go.ug/wp-content/uploads/2024/07/PRESENT-AND-FUTURE-FIBER-OPTIC-NETWORK-July-2024-REV-E.pdf ([archive.org](https://web.archive.org/web/20240901044816/https://uetcl.go.ug/wp-content/uploads/2024/07/PRESENT-AND-FUTURE-FIBER-OPTIC-NETWORK-July-2024-REV-E.pdf)).  Some effort has been made to ensure that the Points of Presence at power grid substations are accurate but most are guesses. The network paths between the PoPs are approximations only.  It is intended for demonstration purposes only. Only optic fibre up to 2026 is captured.
